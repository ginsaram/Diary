# 제국아 말벗

연제국 어르신을 위한 스마트폰 음성 말벗 웹앱입니다.
API 키 없이도 목소리로 말을 걸고, 어르신 말씀을 듣고, 대화를 이어 갑니다.

- 앱 주소: https://ginsaram.github.io/Diary/jeguk-talk/
- 코드 위치: https://github.com/ginsaram/Diary 의 `gh-pages` 브랜치 `jeguk-talk/` 폴더 (기존 다이어리 앱 파일은 건드리지 않았습니다)

## 무엇을 하나요

- **먼저 말을 겁니다.** 아침·점심·오후·저녁 시간대에 맞춰, 오늘 날씨(맑음·비·눈·더위·추위)를 반영해 다정하게 말을 겁니다.
- **말을 듣습니다.** [눌러서 대답하기]를 누르고 말씀하시면 한국어로 알아듣습니다.
- **대화를 이어 갑니다.** 산책·식사·가족·옛날이야기·잠·아픈 곳 등 25가지 화제에 맞춰 공감하고 다음 질문을 던집니다. 기억을 시험하는 질문은 하지 않습니다.
- **날씨를 알려 줍니다.** Open-Meteo(무료, 키 불필요)에서 오늘 기온과 날씨를 가져옵니다. 기본 지역은 충남 아산시 배방읍입니다.
- **아침 6시에 먼저 인사합니다.** 화면이 켜져 있을 때 설정한 시각에 인사합니다. 휴대폰을 충전기에 꽂아 두면 화면이 꺼지지 않게(지원 기기) 유지합니다.
- **대화 기록을 남깁니다.** 가족 설정에서 어르신이 하신 말씀을 날짜별로 볼 수 있고, 파일로 저장할 수 있습니다.

## 아버님 휴대폰에 설치하기

1. 크롬(안드로이드) 또는 사파리(아이폰)로 위 주소를 엽니다.
2. **[시작하기]** 를 한 번 누릅니다. (이때 소리와 마이크 사용을 허락해 주세요.)
3. 홈 화면에 추가:
   - 안드로이드 크롬: 오른쪽 위 ⋮ → **홈 화면에 추가**
   - 아이폰 사파리: 공유 버튼 → **홈 화면에 추가**
4. 홈 화면의 아이콘을 눌러 앱처럼 엽니다.

## 가족 설정 열기

오른쪽 위 **톱니바퀴(⚙)를 2초쯤 길게** 누릅니다. (어르신이 잘못 들어가지 않도록 길게 누르기로 했습니다.)
길게 누르기 대신 주소 끝에 `#family`를 붙여도 설정이 바로 열립니다. 가족 휴대폰에 이 주소를 북마크해 두시면 편해요.

설정할 수 있는 것:

| 항목 | 설명 |
|---|---|
| 호칭 | 부르는 이름 (기본: 제국아) |
| 아침 인사 | 자동 인사 켜기/끄기, 시각 변경(기본 06:00), 지금 인사 듣기 |
| 목소리 | 말하기 속도(기본 0.92), 목소리 선택(자동 = 가장 자연스러운 목소리), [이 목소리 들어보기]·[목소리 차례로 듣기]로 직접 들어보고 고르기 |
| 대화 | 대답 자동으로 듣기, 화면 켜 두기 |
| 지역 | 동네 이름으로 찾기(예: 아산, 유구), 휴대폰 위치 사용 |
| 대화 기록 | 보기, 파일로 저장(.txt), 지우기 |
| 고급(선택) | OpenAI 또는 Gemini API 키를 넣으면 대화가 더 자유로워짐 (키는 이 휴대폰 브라우저에만 저장). 대화 목소리도 OpenAI TTS(nova/onyx 등)로 바꿀 수 있음 |

## 알아 두실 점

- 브라우저 앱은 **완전히 꺼지면** 정해진 시각에 알람을 울릴 수 없습니다. 그래서 앱을 켜 두거나 홈 화면에서 열어 두시는 것이 좋습니다. 대신 [말 걸어줘] 버튼과 시간대별 인사 버튼(아침·점심·오후·저녁)으로 언제든 말을 걸 수 있습니다.
- 아이폰 사파리는 마이크로 말을 알아듣는 기능(Web Speech Recognition)을 지원하지 않습니다. 그때는 화면 아래 큰 버튼(좋지 / 피곤혀 / 산책 가자 / 다시 말해줘)으로 대답하시면 됩니다.
- 목소리는 휴대폰에 설치된 한국어 음성(TTS)을 씁니다. 휴대폰에 인터넷 목소리(Google·Microsoft Natural)가 있으면 그것을 먼저 고르고, 인터넷이 끊기면 휴대폰 목소리로 이어서 읽습니다. 가족 설정의 [목소리 차례로 듣기]로 이 휴대폰에 있는 목소리를 다 들어보고 제일 자연스러운 것을 고를 수 있습니다. (어르신 휴대폰에 삼성 TTS만 있고 Google 음성 합성이 없으면, 설정 → 일반 → 텍스트 음성 변환에서 Google을 고르거나 한국어 음성을 설치해 주세요.)
- 모든 대화 기록과 설정은 **그 휴대폰 브라우저 안에만** 저장됩니다. 서버로 보내지 않습니다. (고급 API를 켠 경우에만 대화 내용이 그 API로 전송됩니다.)

## 고칠 때 (배포 방법)

코드는 워크스페이스 `/workspace/jeguk-talk` 에 있고, 배포본은 `ginsaram/Diary` 저장소 `gh-pages` 브랜치의 `jeguk-talk/` 폴더입니다.

1. 파일을 고친 뒤 `index.html`의 `?v=` 숫자와 `sw.js`의 `CACHE` 이름을 하나 올립니다. (휴대폰에 저장된 예전 파일을 새로 받게 하는 표시)
2. 고친 파일을 `gh-pages` 브랜치의 `jeguk-talk/` 폴더에 복사하고 커밋·푸시합니다.
3. 30초~1분 뒤 `https://ginsaram.github.io/Diary/jeguk-talk/` 를 열어 확인합니다.
